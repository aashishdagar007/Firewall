Welcome to the AGEIS XII Setup Wizard.

AGEIS XII is a custom Application-Layer firewall. 

OVERVIEW
Unlike standard firewalls that only filter based on ports and IP addresses, AGEIS XII operates at Layer 7. It utilizes protocol multiplexing to allow custom, predefined security protocols to operate stealthily alongside standard web traffic on a single port.

SYSTEM REQUIREMENTS
- Windows Operating System
- Administrator Privileges (Required for opening raw network sockets and binding to system ports).

Note During execution, Windows User Account Control (UAC) will prompt you for elevated permissions. This is required for the packet capture engine to function.
