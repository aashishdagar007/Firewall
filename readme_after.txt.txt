Installation Complete! Thank you for installing AGEIS XII.

GETTING STARTED:
1. Launch the firewall using the desktop shortcut or the Start Menu folder.
2. Click "Yes" on the Administrator prompt to allow the firewall engine to bind to your network interfaces.
3. The firewall will silently begin intercepting and routing traffic based on your predefined multiplexing rules.

CONFIGURATION & LOGS:
Your installation includes specific directories for management:
- /config: Contains your predefined protocol rules and signature bytes.
- /dashboard: Contains the localized user interface components.
- /logs: Network intercepts and dropped packet telemetry will be recorded here.

To stop the firewall, simply close the command window or use the provided dashboard interface.
