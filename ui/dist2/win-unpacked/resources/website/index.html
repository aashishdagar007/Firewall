Installation Guide

Get Up & Running in Minutes

Follow these steps to install AEGIS XII on your Windows machine. Administrator privileges are required to enable packet capture.

01

Download the Installer

Click the Download v3.0 Installer button below. The file is AEGIS_XII_Setup_v3.exe (~79 MB). Save it anywhere on your system.

Your browser may warn about running .exe files — click Keep or Run anyway.
02

Accept the UAC Prompt

Windows will display a User Account Control dialog asking for Administrator permission. Click Yes to proceed.

Administrator access is required — raw socket packet capture cannot function without it.
03

Run the Setup Wizard

The AEGIS XII Setup wizard will open. Choose your preferred installation directory (default: C:\Program Files\AEGIS XII\) and click Install.

  • Start Menu shortcut is created automatically
  • Desktop shortcut is optional
  • Installation takes under 30 seconds
04

AEGIS XII Starts Automatically

After installation, AEGIS XII launches immediately and runs silently in the background. Look for the shield icon in the system tray (bottom-right, near the clock).

Tips & Troubleshooting

  • Can't see the tray icon? Click the ^ chevron in the bottom-right to expand hidden icons. Right-click taskbar → Taskbar settings to pin it permanently.
  • Firewall not capturing? Make sure you accepted the UAC prompt. Re-launch from Start Menu as Administrator if needed.
  • Uninstall: Go to Settings → Apps → AEGIS XII → Uninstall. All files and registry entries are removed cleanly.
  • Auto-starts on login — this is by design. Terminate from the tray if you want to stop it without uninstalling.
