# Project Charter & RACI

## Vision
Provide an enterprise‑grade firewall service with high availability, low latency, and strict security compliance.

## Success Criteria
- Availability ≥ 99.95 %
- Latency ≤ 20 ms under peak load
- Zero critical CVEs in first 30 days
- NPS ≥ 90 % from beta customers
- 24/7 on‑call rotation staffed

## Scope
- Core packet‑filter engine
- Management UI & API
- Deployment on Kubernetes (AWS/EKS)
- Monitoring, alerting, and logging stack
